# 🌍 Personalized Travel Itinerary Planner

An autonomous web planner that generates structured, day-wise itineraries based on destination, trip duration, travel companions, and preferred vibe.

## ✨ Features
- **Dynamic Trip Generation**: Supports global destinations with morning, afternoon, and evening breakdowns.
- **Smart Presets**: Instant one-click starters for popular destinations (Jaipur, Tokyo, Rome, Bali).
- **Interactive Timeline Controls**: Mark visited, swap alternative stops, and direct Google Maps routing.
- **Offline & Print Ready**: Export clean PDF itineraries directly.

## 🚀 Run in VS Code
Open the folder in VS Code, then open `index.html` in your browser.
